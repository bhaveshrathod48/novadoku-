# Nova artwork and source record

The [approved reference sheet](reference/novadoku-ui.jpg) supplied Nova's identity and poses. The built-in ImageGen tool generated the art from the corresponding reference panels. Selected renders were trimmed, registered at a shared scale within each atlas, and encoded as transparent WebP. The grid portrait is a smaller encode of the tutorial portrait.

| Asset | Reference and purpose |
| --- | --- |
| `assets/characters/nova/nova_full_body.webp` | Standing Nova from Home. |
| `nova_portrait.webp`, `nova_grid.webp` | Near-frontal tutorial portrait and compact board-cell texture. |
| `nova_hint.webp` | Curious, angled hint portrait. |
| `nova_retry.webp` | Seated Nova with a closed-eye reassuring smile. |
| `nova_victory.webp` | Closed-eye victory laugh. |
| `nova_daily.webp` | Full-body play bow with the raised violet tail. |
| `assets/animations/nova/nova_*.webp` | Ten atlases with four authored poses each. |

The visual review compared the stills and atlas poses on lavender backgrounds. It checked Nova's face, violet eyes, white fur, swept forelock, pink ears, purple tail, and N bandana, plus posture and expression against the relevant panels. Minor differences in fur shading, iris highlights, and stitch thickness remain in the reconstructed art. Sprite playback holds each of the four poses for a specified duration. The player eases between expressions.

```text

The image stream retains the current/next playback frames according to Flutter's codec/cache policy; this is not a claim that the entire player uses only one frame's memory.
